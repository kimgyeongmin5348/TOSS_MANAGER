PORTO 전체 개발 계획표
======================

작성일: 2026-08-16
기준: 1인 개발 약 6~8주


1. 전체 로드맵
--------------

[0단계] 개발·테스트 환경 정상화 (1~2일 / 필수)
[1단계] 포트폴리오 중심 화면 재구성 (4~6일 / 최우선)
[2단계] 스냅샷과 데이터 신뢰성 개선 (4~5일 / 최우선)
[3단계] 보안과 사용자 계정 기능 보완 (4~6일 / 높음)
[4단계] 관심종목 기능 완성 (3~5일 / 높음)
[5단계] 성과·자산배분 분석 추가 (1~2주 / 높음)
[6단계] 다중 계좌 관리 개선 (3~5일 / 중간)
[7단계] 운영·배포 안정화 (1주 / 출시 전 필수)
[8단계] 주문 기능 고도화 (별도 진행 / 마지막)


2. 단계별 작업
--------------

[0단계] 개발 환경 정상화

목표:
- 기능을 수정할 때 기존 기능이 깨졌는지 바로 확인할 수 있는 상태 만들기

할 일:
- 깨진 .venv 재생성
- pytest를 개발 의존성으로 등록
- 전체 테스트 실행 및 실패 항목 수정
- 린트와 기본 타입 검사 도입
- .env.example과 실제 설정 항목 재점검
- 커밋마다 테스트가 실행되는 CI 구성

완료 기준:
- 새 PC에서도 문서대로 설치·실행 가능
- 전체 테스트 통과
- 커밋마다 자동 테스트 실행


[1단계] 포트폴리오 홈 만들기

목표:
- 로그인 직후 내 전체 자산 상태를 한눈에 볼 수 있게 만들기

메뉴 개편:
- 현재: 시장·차트 / 조건주문
- 변경: 홈 / 포트폴리오 / 시장 / 관심종목 / 조건주문

홈 화면 추가 항목:
- 전체 평가금액
- 총 매입금액
- 전체 평가손익
- 오늘 손익
- 보유 종목 수
- 마지막 동기화 시각
- 원화·달러 자산 비중
- 상위 보유 종목
- 포트폴리오 위험 요약
- 최근 포트폴리오 변화

포트폴리오 화면 추가 항목:
- 전체 계좌 통합 보기
- 계좌별 보기
- 보유 종목 표
- 종목별 평가금액·비중·수익 기여도
- 자산배분 차트
- 저장 데이터와 실시간 데이터 구분

완료 기준:
- 로그인 후 첫 화면에서 전체 자산 상태 파악 가능
- 시장 화면을 열지 않아도 Porto의 핵심 기능 확인 가능
- 좁은 화면에서도 주요 정보가 깨지지 않음


[2단계] 스냅샷 저장 개선

목표:
- 중복 저장을 줄이고 데이터 기준 시각과 저장 상태를 명확하게 만들기

저장 정책:
- 실시간 연결 직후 1회 저장
- 사용자가 누르는 '현재 상태 저장' 버튼 추가
- 보유 내역이 같으면 중복 저장 방지
- 장중 스냅샷 저장 간격 제한
- 장 마감 스냅샷 별도 보존
- 오래된 장중 스냅샷 정리 정책 마련

오류 처리:
- 토스 조회와 DB 저장 오류 분리
- DB 저장에 실패해도 실시간 조회 화면은 계속 표시
- 저장 실패 안내와 재시도 기능 제공

표시 항목:
- 마지막 실시간 조회 시각
- 마지막 DB 저장 시각
- 저장 성공·실패 상태
- 오래된 데이터 경고

완료 기준:
- DB 장애가 발생해도 실시간 계좌 조회 가능
- 중복 스냅샷이 무제한 생성되지 않음
- 모든 저장 데이터의 기준 시각 확인 가능


[3단계] 보안과 계정 관리

먼저 적용할 항목:
- 로그인 실패 횟수 제한
- 일정 횟수 실패 시 임시 잠금
- 사용자·종목·뉴스 등 HTML 동적 값 이스케이프
- 로그인 세션 만료
- 비밀번호 변경
- 로그아웃 처리 통일
- 내부 오류와 사용자 오류 메시지 분리

이후 적용할 항목:
- 이메일 인증
- 비밀번호 재설정
- 회원탈퇴
- 사용자 데이터 삭제
- 연결된 계좌 확인 및 해제
- 개인정보 처리 안내

완료 기준:
- 반복 로그인 공격 제한
- 동적 문자열을 통한 HTML 삽입 차단
- 비밀번호 변경과 회원탈퇴 가능
- 탈퇴 시 삭제·보존되는 데이터가 명확함


[4단계] 관심종목 완성

목표:
- 이미 존재하는 watchlist_items 테이블을 실제 기능으로 연결

할 일:
- 종목 상세에 관심종목 추가·해제 버튼
- 관심종목 목록 화면
- 사용자 메모
- 목표가격 설정
- 현재가 대비 목표가격 차이
- 관심종목 뉴스 요약
- 관심종목 수정·삭제
- 시장별 필터

알림 개발 순서:
- 1차: 앱 내부에서 목표가 도달 여부 표시
- 2차: 이메일·Slack·푸시 등 외부 알림

완료 기준:
- 다시 로그인해도 관심종목 유지
- 사용자별 관심종목 완전 분리
- 목표가격 도달 여부를 화면에서 확인 가능


[5단계] 포트폴리오 성과 분석

5-1. 자산배분:
- 종목별 비중
- 국내·미국 비중
- 원화·달러 비중
- 레버리지·인버스 비중
- 상위 3종목 집중도

5-2. 기간별 변화:
- 일·주·월별 평가금액
- 누적 평가손익
- 최고점 대비 하락률
- 이전 스냅샷 대비 변화
- 종목별 수익 기여도

5-3. 벤치마크:
- 국내 포트폴리오와 KOSPI 비교
- 미국 포트폴리오와 S&P 500 비교
- 포트폴리오 최대 낙폭
- 변동성과 위험 대비 성과

5-4. 환율:
- 환율 데이터 저장 기능 연결
- 달러 자산의 원화 환산
- 주가 수익과 환율 수익 분리

주의:
- 입출금 데이터가 없다면 정밀 수익률이 아니라 '평가금액 변화'로 표시

완료 기준:
- 현재 가치뿐 아니라 기간별 변화 확인 가능
- 시장 벤치마크와 같은 기간으로 비교 가능
- 통화가 다른 자산을 같은 기준으로 합산 가능


[6단계] 다중 계좌 관리

할 일:
- 전체 계좌 통합 보기
- 특정 계좌만 선택해서 보기
- 계좌 별칭 지정
- 연결된 계좌 목록
- 계좌 연결 해제
- 토스에서 사라진 계좌 비활성화
- 계좌별 마지막 동기화 시각
- 계좌별 저장 실패 표시

완료 기준:
- 여러 계좌를 불편 없이 관리 가능
- 사라진 계좌가 계속 활성 상태로 남지 않음
- 주문 실행 전에 선택 계좌를 명확히 확인 가능


[7단계] 운영·배포 안정화

DB:
- Alembic 등 마이그레이션 도입
- 스키마 버전 관리
- 백업·복구 절차
- 데이터 보관기간 설정
- 테스트 DB와 운영 DB 분리

로그와 모니터링:
- API 요청 실패 기록
- 공급자별 실패율
- Toss request ID 기록
- DB 연결 장애 기록
- 외부 API 호출량 확인
- 관리자 상태 점검 화면

API 안정성:
- 조회 요청의 429·5xx 재시도
- 지수 백오프
- 공급자별 타임아웃
- 뉴스·재무·AI 장애가 전체 화면에 영향을 주지 않도록 분리
- 주문 요청은 무분별하게 자동 재시도하지 않음

배포:
- 고정 출발 IP
- HTTPS
- 환경변수와 비밀키 관리
- 운영자 연락처와 이용 안내
- 장애 발생 시 복구 절차

완료 기준:
- 외부 API 하나가 실패해도 나머지 화면 사용 가능
- DB 변경 내역을 추적하고 되돌릴 수 있음
- 장애 원인을 로그로 확인 가능


[8단계] 주문 기능 고도화

할 일:
- 주문 체결 상태 추적
- 주문 이벤트 이력
- clientOrderId 영구 저장
- 중복 주문 방지
- 주문 전 예상 금액과 보유 현금 확인
- 주문 가능 수량 검증
- 계좌·종목·수량·조건 최종 확인
- 주문 결과와 실패 사유 저장
- 모의 환경 또는 읽기 전용 검증 모드

완료 기준:
- 타임아웃 발생 후 중복 주문 여부 확인 가능
- 생성부터 체결·취소까지 상태 이력 보존
- 잘못된 계좌 선택 가능성 최소화


3. 실제 착수 순서
-----------------

[1차 작업: 기반과 홈]
1) 테스트 환경 복구
2) 메뉴 구조 개편
3) 포트폴리오 홈 추가
4) 전체 계좌 요약
5) 실시간·저장 데이터 배지

[2차 작업: 데이터 신뢰성]
1) 스냅샷 중복 방지
2) 저장 오류와 조회 오류 분리
3) 마지막 동기화 시각
4) 계좌 비활성화 처리

[3차 작업: 안전성]
1) 로그인 시도 제한
2) HTML 이스케이프
3) 세션 만료
4) 비밀번호 변경

위 3차 작업까지 완료하면 Porto의 1차 완성본으로 판단한다.
그다음 관심종목과 성과 분석을 순서대로 추가한다.


4. 핵심 원칙
------------

- 분석 기능을 무조건 늘리기보다 포트폴리오 관리 경험을 먼저 완성한다.
- 조회 실패와 저장 실패를 분리해 부분 장애에도 앱을 사용할 수 있게 한다.
- 주문 기능은 데이터·계정·운영 안정화가 끝난 후 고도화한다.
- 각 단계는 테스트와 완료 기준을 충족한 뒤 다음 단계로 넘어간다.
